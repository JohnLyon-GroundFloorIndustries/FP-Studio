# The Wild Bouquet Studio

A single-page web toy made for Flora Pacifica. Pick a season, a venue, a color story and a feeling, and a hand-tied Pacific Northwest bouquet grows on screen stem by stem, with a stem recipe and a note for the bride.

- Tap a bloom to see its name, variety and a fun fact.
- Sweep across the bouquet to make a breeze.
- **Regrow** makes a new variation; **Save image** downloads a PNG.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The whole site: markup, styles and code in one file |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is |
| `README.md` | This description |

## Publish with GitHub Pages

1. Upload these files to the root of a repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

Fonts load from Google Fonts, so the page needs an internet connection to display as designed.
